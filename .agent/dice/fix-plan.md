## 目標及範圍

## 執行次序

1. **DICE-1** 與 **DICE-3** 可先分開處理；兩者都會改動解析器邊界，完成後先驗證既有公式行為。
2. **DICE-2** 依賴有效解析結果，並需確立逐次打擊的 PR 規則；完成後以其聯合分佈作為 DICE-4 的依據。
3. **DICE-4** 依賴 DICE-1 至 DICE-3 的公式及資源語義。
4. **DICE-5** 的測試案例應隨各項修正加入；最後執行整套 Dice 回歸測試。

## 檢查點

### CP-1：骰式解析正確

- `1D6 - 1D6` 保留一顆正向 D6 和一顆負向 D6，不互相抵銷。
- 有效的正負骰組合仍能正確解析固定值及骰數。
- `1D6oops`、未匹配括號、尾隨垃圾文字及不支援骰種均明確報錯。
- 驗證錯誤輸入不會被當成零傷害或部分有效公式繼續計算。

### CP-2：每輪 PR 只會使用一次

- PR 只可由該輪第一個命中的打擊消耗；如之前的打擊未命中，後續打擊仍可使用。
- 一旦打擊命中（普通命中或爆擊），之後打擊不可再次取得 PR 傷害。
- PR 骰只在實際套用的打擊上按爆擊倍率計算。
- 驗證 PR 的分支機率與傷害分佈，並確認全分佈機率質量為 1。

### CP-3：最大傷害與 PMF 一致

- PR-only 輪次沒有打擊可施加 PR，分佈與最大傷害皆為 0。
- 每次打擊的傷害低於 0 時按零傷處理；負固定值或減傷骰不會令上限計算與實際分佈不一致。
- 分佈中高於理論最大傷害的桶位皆為零。

### CP-4：回歸及整合驗證

- 現有解析器與管線測試繼續通過，並新增上述邊界案例。
- 測試包括優勢、劣勢、爆擊門檻、爆擊倍率、負向減傷骰、多次打擊及跨輪輸入。
- 所有測試均以可斷言的結果驗證；不可只依賴 `console.assert` 輸出後仍回報成功。

## 測試案例建議

| 範疇 | 輸入／情況 | 預期結果 |
|---|---|---|
| 同面數正負骰 | `1D6 - 1D6` | 保留獨立骰；未觸發零傷下限前的範圍為 -5 至 5。 |
| 非法骰式 | `1D6oops`、不支援骰面、括號不匹配 | 解析明確失敗，不回傳部分有效結果。 |
| PR 延後消耗 | 首擊未命中、次擊命中 | PR 由次擊套用一次。 |
| PR 已消耗 | 首擊命中、次擊命中 | PR 只套用於首擊。 |
| PR-only | 輪次只有 PR、沒有攻擊 | 傷害分佈集中於 0；理論最大傷害為 0。 |
| 逐擊零傷下限 | 多擊各自可能為負傷害 | 每擊先將傷害下限套用至 0，再累加總傷害。 |

- CP-1 至 CP-4 全部通過。

- 不改動 i18n 或無關模組；Dice 公式語法及 PR 語義有清楚的驗證規則。
