## 檢查點

### CP-1：骰式解析正確 — 已完成

- `1D6 - 1D6` 保留一顆正向 D6 和一顆負向 D6，不互相抵銷。
- 有效的正負骰組合仍能正確解析固定值及骰數。
- `1D6oops`、未匹配括號、尾隨垃圾文字及不支援骰種均明確報錯。
- 驗證錯誤輸入不會被當成零傷害或部分有效公式繼續計算。

### CP-2：每輪 PR 只會使用一次（數學點 1）— 已完成

- 採用 2-State DP 狀態轉移，單輪內僅有單一 PR 資源池。
- PR 只可由該輪第一個命中的打擊消耗；如之前的打擊未命中，後續打擊仍可使用。
- 一旦某次打擊命中（普通命中或爆擊），後續所有打擊確定無法再獲得 PR 傷害，分佈中絕不出現雙重 PR 組合。
- PR 骰只在實際套用的打擊上按爆擊倍率計算。
- 驗證各分支機率與傷害分佈；截尾 PMF 的數值質量可低於 1，差額須由 `discardedMass` 記錄，不得重新分配。

### CP-3：最大傷害與 PMF 一致（數學點 2）— 已完成

- 理論上限計算在每擊單獨套用 $\max(0, \text{dmg})$，負傷害打擊不會倒扣其他打擊的上限（如 `(-1D4, 1D4)` 上限必須為 8）。
- PR-only 輪次因沒有任何打擊可施加 PR，分佈與最大傷害皆為 0（如 `(1D4PR)` 上限必須為 0）。
- 全戰鬥理論最大傷害保證嚴格等於 PMF 的最高支撐桶，即使該桶數值質量因 epsilon 截尾而為零；高於理論最大傷害的桶必須沒有支撐。

### CP-4：多重 D20 優劣勢 PHB 抵銷正規化（數學點 3）— 已完成

- 命中公式支援組合生成的多個 D20 條件片段（例如 `D20A1 + D20D1 + 5`）。
- 若命中公式中同時出現 A（如 `A1`、`A2`）與 D（如 `D1`），不論數量或階數，依 PHB 規則完全互相抵銷，正規化為常規投骰（`NORMAL`，`advantageMode = 0`）。
- 若僅有同類條件（如多個 A），不累加骰數，取最高階（如 `A2` 優先於 `A1`）。
- 嚴格拒絕不支援的階數（如 `D20A3`）及負號 D20，不可靜默降級。

### CP-5：數值精度與 Epsilon 剪枝防漂移（數學點 4）— 已完成

- 釐清應用層截尾與浮點捨入漂移之界線；小於 `BUCKET_EPSILON` 的桶保留支撐但不參與後續數值摺積，截尾質量不採用等比回縮灌回保留桶。
- 驗證 FFT 與反變換之數值對稱性，確保各桶位在數值誤差範圍內維持單調性與理論分佈一致。

### CP-6：回歸及整合驗證 — 已完成

- 現有解析器與管線測試繼續通過，並新增上述所有數學檢查點之針對性測試。
- 測試包括 30D4／600D4 極值支撐、後續摺積偏移傳遞、epsilon 邊界、內部不可能桶、截尾質量不回灌、支撐-only 列印，以及優勢、劣勢、爆擊、負向減傷、多次打擊、跨輪、多重 D20 與 PR。
- 所有測試均以可斷言的結果驗證；不可只依賴 `console.assert` 輸出後仍回報成功。
