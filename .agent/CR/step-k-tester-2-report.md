## Contract and execution

The Step K contract requires one level-20 single-class character per subclass, STR/DEX/CON/INT/WIS/CHA 14 (+2 modifiers), PB +6, TCE features off, and a complete resource-set comparison (pool key, current/max and formula, recovery, class/subclass/source, costs and gates). The expectation oracle is [class-resource-recovery-reference.md](./class-resource-recovery-reference.md) (Bard lines 49–62, Cleric lines 62–72, Rogue lines 135–141); the fixture and IDs are in [CR-class-resources-plan.md](./CR-class-resources-plan.md) (contract and case list around lines 99–196).

The browser run used one unique temporary character, `__stepk_tester2_20261019_0025__`, and the UI’s class-level apply/confirm flow. The browser origin was a new local HTTP port, and its localStorage was snapshotted before inserting the fixture. No user character was used. The actual values below were read from that character’s persisted generated-resource records after each apply. The app was not edited.

The level-20 common expected outputs used for comparisons:

- **Bard:** `class:hit-dice:d8` 20/20, long rest; spell slots 1–9 = 4/3/3/3/3/2/2/1/1, long rest; one `class:bard:bardic-inspiration` pool at CHA modifier 2 (minimum 1), short-rest recovery from Bard 5, and Superior Inspiration’s +1 when empty on initiative at level 20. Subclass uses of Bardic Inspiration must not create duplicate pools.
- **Cleric:** `class:hit-dice:d8` 20/20, long rest; spell slots 1–9 = 4/3/3/3/3/2/2/1/1, long rest; one `class:cleric:channel-divinity` pool with max 3 (level progression 2/6/18), short-rest recovery; Divine Intervention must represent its 7-day lockout after a successful use, not an ordinary long-rest recovery. Harness Divine Power was off.
- **Rogue:** `class:hit-dice:d8` 20/20, long rest. The PHB class feature Stroke of Luck is expected as a fixed 1-use Rogue class pool, short-or-long-rest recovery, for every level-20 Rogue regardless of archetype. Arcane Trickster’s PHB level-20 table gives 4/3/3/1 slots at levels 1–4, long rest; its Spell Thief feature is 1/LR.
